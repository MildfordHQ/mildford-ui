# Changelog

## 0.0.1 — first public release

Material 3 Expressive React components for operational control planes and creative tools. Every interactive component is built on React Aria Components, styled with CSS Modules and CSS custom-property tokens, and documented in Storybook.

### Foundations

- Tokens in three tiers: M3 color roles (`--md-sys-color-*`), semantic roles (`--mild-color-*`), and component tokens. Shape, elevation (`--mild-elevation-0…3`, `-artboard`), motion (`--mild-motion-*`, zero under reduced motion), M3 type roles (`--mild-type-*`, `--mild-tracking-*`), editor frame sizes, breakpoints and a `--mild-z-*` ladder.
- Light and dark themes via `data-theme`; two palettes via `data-palette`: `neutral` (default) and `cobalt`. Palettes are generated by `pnpm generate:palette` from `scripts/palettes.ts` (Material Color Utilities plus reasoned overrides), with a WCAG contrast table asserted in CI.

### Components

- Actions: `Button`, `IconButton`, `ToggleButton`, `ToggleButtonGroup`, `ButtonGroup`, `Chip`, `SplitButton`.
- Menus and overlays: `Menu` (`MenuTrigger`, `MenuItem`, `MenuSection`, `SubmenuTrigger`), `ContextMenu`, `Popover`, `Tooltip`, `Dialog`.
- Inputs: `FormField`, `TextField`, `TextArea`, `Checkbox`, `Switch`, `Slider`, `Select`, `Dropdown`.
- Color: `ColorSwatch`, `ColorSwatchButton`, `SwatchGrid`, `ColorPicker`, `ColorPickerPopover`, `DualSwatch`.
- Status and feedback: `Badge`, `StatusIndicator`, `Alert`, `EmptyState`, `Spinner`.
- Display: `Card`, `MetricCard`, `Table`, `ProgressStepper`, `Icon`, `Kbd`, `Separator`.
- Patterns for control planes: `AppShell`, `PageHeader`, `SectionHeader`, `SegmentedNavigation`.
- Patterns for editors: `EditorShell` (+ `useWorkspaceViewport`, `useEditorShell`), `TopAppBar`, `NavigationRail` (+ `NavigationRailItem`, `NavigationRailDivider`, bar variant below 1024px), `SidePanel`, `Toolbar`, `FloatingToolbar`.

### Deprecated

- `Dropdown`: use `Select` for value choice or `Menu` for actions.
- `Button`'s `iconOnly`: use `IconButton`, which requires an accessible label.

### Packaging

- ESM with one module per source file and `"sideEffects": ["**/*.css"]`, so consumers bundle only what they import. `react-aria-components` is the only runtime dependency; React 18 is a peer dependency.
- Import `@mildford/ui/tokens.css` once and `@mildford/ui/style.css` for component styles.

### Known limitations

- React Aria has no menubar: app-bar menus are independent; moving between open menus is a click.
- Disabled menu items are skipped by arrow keys (React Aria has no focusable-disabled option for menus); put the reason in the item's description.
- `SwatchGrid` reorders by keyboard only (Alt/Option + ←/→); pointer and touch drag are not supported yet.
- `SwatchGrid` keys swatches by color value, so colors must be unique and `id` is not the swatch identity.
